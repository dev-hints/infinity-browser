## Iteration 2 - Window, Tabs, and Navigation
- `browser_window.py` is the central orchestrator: it creates managers (settings/history/bookmarks/passwords/notes), initializes `TabManager`, `DownloadManager`, optional `AdBlocker`, and binds everything to UI.
- Custom frameless window with a bespoke `TitleBar` and custom controls for minimize/maximize/close.
- Global app-level `eventFilter` captures shortcuts even when `QWebEngineView` has focus.
- Supported shortcuts include:
	- `Ctrl+O` open file
	- `Ctrl+B` bookmarks
	- `Ctrl+H` history
	- `Ctrl+J` downloads
	- `Ctrl+P` print PDF
	- `Ctrl+T` new tab
	- `Ctrl+W` close tab
	- `Ctrl+R` reload
	- `Ctrl+L` focus URL bar
	- `Ctrl+Shift+N` notes
- `NavigationBar` handles URL/search parsing, local file paths, bookmark toggling, and per-tab UI refresh (back/forward state + bookmark star state).
- `TabManager` owns a dedicated `QWebEngineProfile` (`InfinityProfile`) and installs a custom scheme handler for `infinity://` pages.
- `BrowserTab` uses a stacked layout to switch between `QWebEngineView` and `MediaPlayerWidget` for local media extensions.
- History is recorded only for non-internal pages (`url.scheme() != "infinity"`).
- Potential bug noted: `TabManager.navigate_home()` calls `self.load_url(self.new_tab_url)`, but `self.new_tab_url` is not defined in `TabManager`.

## Iteration 3 - Persistence, Privacy, and Feature Managers
- `SettingsManager` uses `settings.json` with default merge behavior for forward compatibility when new keys are added.
- Search engine templates are hardcoded and user-selectable via `search_engine`; query URL is generated by `get_search_url(query)`.
- `HistoryManager` stores latest-first entries in `history.json`, capped at 1000 items.
- History intentionally excludes `devtools://`, `file://`, and `new_tab.html` URLs.
- `BookmarkManager` stores bookmarks as `{url: title}` JSON map in `bookmarks.json`.
- `AdBlocker` is a `QWebEngineUrlRequestInterceptor` with a static domain substring blocklist; matching requests are blocked and counted.
- `NotesManager` stores notes in `notes.json` with UUID IDs, creation/modified timestamps, autosave debounce, search, rename, copy, and delete workflows.
- `PasswordManager` stores credentials in `passwords.json` and local key in `.vault.key`.
- Password cryptography details (implementation):
	- Random 32-byte key persisted locally.
	- Encryption: XOR stream derived from `SHAKE-256(key + nonce)`.
	- Integrity: `HMAC-SHA256(nonce + ciphertext)`.
	- Storage format: base64 of `nonce || ciphertext || mac`.
	- File permissions are tightened with `chmod 600` where possible.
- Note: README/about text says AES-equivalent/PBKDF2; implementation uses custom SHAKE-based stream + HMAC rather than AES.
- `DownloadManager` is profile-bound (`downloadRequested` signal), supports `ask` and `auto` modes, auto-creates download dir, tracks active tasks and persisted history (`downloads.json`).
- Download UI supports cancel/open/folder actions, size/speed/progress rendering, history cleanup, and redownload via opening original URL in a new tab.

## Iteration 4 - Settings UI, Internal Pages, and Packaging
- `SettingsDialog` is a 5-tab panel (General, Appearance, Privacy, Security, Downloads) with immediate write-through via `SettingsManager.set()` and runtime application (`_apply_live_settings`).
- Live-applied settings include JS enable/disable, popup blocking behavior, default font size, nav home button visibility, and zoom factor across all open tabs.
- Privacy clear actions:
	- Cache and cookies are cleared via `QWebEngineProfile` APIs.
	- Potential bug in `_clear_history()`: it assigns `win.history_manager.bookmarks = {}` (wrong property) and only writes `history.json` directly, rather than calling manager API (`clear_history()`).
- Custom internal URL scheme:
	- `scheme_handler.py` registers `infinity://` as secure/local/CORS-enabled.
	- `InfinitySchemeHandler` currently serves `infinity://newtab` from `new_tab.html` only.
- `new_tab.html` is a styled static start page with:
	- animated starfield background,
	- central search box,
	- fixed quick links (GitHub/YouTube/Reddit),
	- JavaScript search submission hardcoded to Google.
- Important behavior gap: new-tab search always uses Google and does not read the selected search engine from settings.
- `MediaPlayerWidget` acts as a fallback launcher for local media files; it opens media using system player (`xdg-open` / `open` / `os.startfile`) rather than in-app decode/render.
- Global app theme is centralized in `styles.qss` (dark palette, styled tabbar, custom close-tab icons, URL bar, title/nav controls).
- Linux installer flow (`install.sh`):
	- installs Python deps with `pip --user`,
	- installs app icon into local icon theme,
	- generates `~/.local/share/applications/infinity-browser.desktop` from template,
	- optionally pins app to GNOME favorites via `gsettings`.
- Desktop entry launches: `python3 __INSTALL_DIR__/main.py %u`, with icon key `infinity-browser`.
